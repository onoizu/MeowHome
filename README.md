# MeowHome 前端项目

COMP3421 猫咪领养与养护网站。使用 **HTML + CSS + 原生 JavaScript**，没有 React、Vue、npm 依赖、打包工具、后端业务接口或数据库。

## 如何打开

推荐在这个目录运行一个静态文件服务器：

```sh
cd /Users/songxiajinzhi/Desktop/COMP3421/proj/MeowHome
python3 -m http.server 8086 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8086`。VS Code 的 Live Server 也可以使用。请固定使用同一地址和端口，浏览器本地记录按来源区分。

静态服务器只负责发送 HTML、CSS、JavaScript 和图片，不包含后端业务逻辑。`file://` 可以浏览基本页面，但不同浏览器对本地文件的存储规则不同，不适合完整演示。

## 页面文件：每个 HTML 负责什么

- `index.html`：精简首页。主图、六张猫咪照片，以及配对、照护和故事入口。
- `discover.html`：领养广场。搜索、品种/年龄/性别/地区/状态筛选、排序、分页。
- `cat.html`：单只猫咪详情。通过 `?id=milo` 等参数选择猫咪，包含收藏、领养申请弹窗和公开日记。
- `match.html`：五步偏好问卷。展示个性化排序和推荐理由。
- `rehome.html`：三步送养表单。基本资料、照片与性格照护信息、提交前预览；支持 `?edit=猫咪ID` 编辑自己的可编辑发布。
- `guides.html`：新手指南。文章弹窗和可保存进度的接猫准备清单。
- `stories.html`：公开领养日记。列表和全文阅读弹窗。
- `dashboard.html`：个人中心。我的申请、我的发布、收藏、日记、资料；演示管理员可见发布审核入口。
- `login.html`：本地身份演示。预设领养者/送养者/管理员，也可以创建不含密码的本地资料。

## CSS 文件

- `css/base.css`：全站基础样式。颜色与字体变量、布局容器、导航、页脚、按钮、卡片、表单、提示、弹窗及公共响应式规则。
- `css/pages.css`：详情、问卷与发布、指南、日记、个人中心、登录等页面的专用布局。
- `css/discover.css`：领养广场的左侧 sticky 筛选、可展开分组、结果网格及手机折叠样式。
- `css/home.css`：首页独立布局，包括主图、纯照片网格、悬停资料和简化入口；不会改变领养广场的资料卡。

调色主要修改 `base.css` 的 `:root` 变量；首页布局修改 `home.css`，领养广场布局修改 `discover.css`，其余页面修改 `pages.css` 对应注释段落。没有把整页 CSS 写进 HTML。

## JavaScript 文件

所有页面按顺序加载 `data.js → store.js → translations.js → i18n.js → common.js → 当前页脚本`，使用 `defer`，无需模块打包或构建。

- `js/data.js`：猫咪、演示用户、申请、故事、清单与问卷的初始示例数据；`breedGroups` 是筛选与发布共用的品种目录。
- `js/store.js`：唯一的本地数据适配层。读写 localStorage、保存当前演示身份，统一维护发布、申请、收藏、日记和清单。**不是服务器或数据库。**
- `js/translations.js`：英文与繁體中文的界面文案字典；扩展译文主要修改此文件。
- `js/i18n.js`：即时切换语言、保存语言偏好，以及更新动态文字；保留输入、选项数据值和 URL，不刷新页面。
- `js/common.js`：公用图标、导航、移动菜单、猫咪卡片、安全文本处理、提示、图片压缩与弹窗工具；负责点击下拉、外部关闭、键盘操作及共用品种选项生成。
- `js/home.js`：首页照片网格。电脑悬停或键盘聚焦时显示资料；触屏首次点按展开，再次点按进入详情。
- `js/discover.js`：组合筛选、250ms 搜索防抖、排序、分页、URL 参数同步及前进后退恢复。
- `js/cat.js`：详情页渲染、公开关联日记、申请表单验证与提交。
- `js/match.js`：问卷前进/后退、记录答案、个体特征规则评分和推荐解释。
- `js/rehome.js`：分步校验、图片预览、资料预览、创建/编辑猫咪发布。
- `js/guides.js`：固定指南文章和准备清单交互。
- `js/stories.js`：只展示公开日记、打开全文阅读弹窗。
- `js/dashboard.js`：个人中心切换、申请审核、实际交接确认、日记增删改、资料修改和演示审核。
- `js/login.js`：切换本地演示身份、创建本地资料、安全限制返回页面路径。

## 可以怎样演示

1. 浏览首页，在猫咪照片上悬停查看资料，再打开领养广场组合筛选；刷新或使用浏览器后退验证条件保留。
2. 登录页输入 **meihui@example.test**；收藏猫咪、完成偏好问卷、提交申请。Milo 已有示例申请，可选择其他猫咪申请。
3. 登出后用 **chengyan@example.test** 登录，在“我的发布”查看 Milo 的示例申请，开始沟通或接受申请。
4. 接受申请只把猫咪设为 `reserved`，暂停新申请；点击“Confirm handover”才设为 `adopted`，并关闭其他未处理申请。
5. 切回 Meihui 查看更新的进度；在“我的日记”为已领养的 Maple 或新完成领养的猫咪创建记录，测试公开/私密、编辑、删除。
6. 创建新送养发布后，切换 **moderator** 演示身份，在个人中心批准发布；回到广场查看。
7. 在指南页勾选清单，刷新后验证保存效果；缩窄浏览器观察响应式布局。

## 明确的演示范围

- 所有变化只保存在当前浏览器的 `meowhome-demo-v1` localStorage 中；换设备不会同步。
- 没有真实账号、密码、Session、HTTP API、数据库、消息发送或实际领养服务。
- JavaScript 的身份/可见性判断仅展示未来产品行为；用户可通过开发者工具查看或修改本地记录，不能视为安全保护。
- 照片仅允许 JPG/PNG/WebP，最大 5MB；浏览器缩放压缩后本地存储。空间不足时提示失败并回滚本次数据变化。
- 推荐只使用能量、照护需求、经验、已有宠物和年龄偏好等简单规则，不需要 AI，也不保证真实适养性。
- 应用状态：`pending → contacting → accepted → completed`，以及 `rejected / withdrawn / closed`。
- 猫咪状态：发布后 `pending`，审核后 `available`，接受申请后 `reserved`，确认交接后 `adopted`。
- 重置方法：个人中心“我的资料”中选择“Reset all local demo data”，会删除本地新增记录并恢复示例。

## 后续接后端时从哪里改

先保持页面和样式不动，将 `store.js` 中的同步本地读写改为异步 Fetch 请求，再调整页面脚本等待结果。身份认证、权限验证、输入验证、申请状态一致性和文件安全必须在服务器重新实现，不能依赖前端判断。

示例数据实际上包含收藏、日记、清单等关系，因此未来数据库设计不应局限于 Users、Cats、Applications 三张表。当前任务不实现这些后端内容。

## 导航、语言与筛选布局

- 所有页面的导航结构一致。“领养与送养”下拉包含寻找猫咪、送养猫咪和偏好配对；“猫咪照护”下拉包含指南与准备清单。
- 下拉通过点击打开，再次点击、点击外部或按 Escape 关闭；方向键下键可打开并聚焦第一个链接。手机先打开折叠导航，再展开对应分组。
- 右上角 EN / 繁體 即时切换界面语言。偏好以 `meowhome-language` 保存，跨页与刷新保持；不修改已填写的表单内容。
- 猫咪的名字、用户姓名等专有名称保持原样。内置示例文案有繁體译文，用户自己撰写的自由文本没有机器翻译服务。
- 领养广场采用左侧筛选、右侧结果布局。桌面筛选栏通过 sticky 保持在导航下方，内容过长时可在栏内滚动；宽度 700px 及以下使用可展开／收起的筛选面板。
- 品种、性别等选项的英文数据值保持稳定，只翻译显示标签；关键词可匹配英文或内置的繁體品种与性格名称。
- 新增功能已在 1440 / 1024 / 768 / 390 / 320px 宽度及两种语言下检查，并重新验证原有领养流程。

## 品种目录与左侧筛选

- 品种共有 15 项，按家猫与混种、短毛品种、长毛品种、无毛品种组织；包括美短、暹罗、孟加拉、俄蓝、布偶、波斯、缅因、挪威森林、西伯利亚等。
- 筛选与发布页面通过 `data-breeds` 标记使用同一份目录，英文数据值固定，分组名称与选项支持繁體切换。
- 每个筛选组使用原生 HTML `details / summary`，可独立折叠，不影响已选条件。
- 没有对应示例猫咪的品种会正常显示空结果，不伪造匹配资料。
- 桌面端栏位固定在导航下方 108px；平板导航较矮时为 94px，且不会覆盖页脚。
- 图书馆参考链接在本次环境无法访问，按用户描述实现左侧分组筛选；品种名称参考 CFA 的公开品种目录：https://cfa.org/breeds/ 。
