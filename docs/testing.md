# MeowHome 测试结果

2026-11-28 在 Node.js 25.5.0、SQLite 和 Chrome 上验证。自动测试使用临时数据库和独立的上传目录。在 `source/` 运行 `npm test`，10 组子测试全部通过（Node 连同外层流程共计 11 项）。

| 填写、修改领养申请；测试省略选填项、超长文字和未勾选同意 | 合法申请可查看和编辑，无效提交收到错误反馈 | 通过 |
